Beranda Screen

6-Action Grid with Persistent Safety STOP

No scrolling or paging required to reach emergency controls. Every core wash action is available in a 3×2 high-contrast grid with bold custom icons designed to match the physical touch pod.

  • ✓ Single-tap triggers: CUCI (Wash), PERAS (Spin), BUANG (Drain), ISI (Fill), BILAS (Rinse), and BILAS ND.
  • ✓ Immediate Emergency STOP: Purges all pending queues and prioritizes shut-off before any motor reversal.
  • ✓ HA-Style Orbiting Spinner: 8-dot animated telemetry ring indicates live cycle progression in real time.
  • ✓ Stale Data Protection: If telemetry pauses >15s, transitions to an amber "DATA BEKU" warning and gates new starts.

Kontrol Screen

Real-Time Relay Indicators & Tub Pressure

The Controls screen acts as a transparent window into the physical hardware. Relays are presented strictly as live state indicators—preventing accidental actuation of conflicting coils while observing motor agitation.

  • ✓ Relay Mirroring: Live feedback for Motor A (CW), Motor B (CCW), Drain Solenoid, and Water Inlet.
  • ✓ Water Sensor ADC Diagnostics: Read analog tub water percentage with raw median-filtered calibration readings.
  • ✓ Firmware & Heap Telemetry: Probe controller memory and runtime health with one tap.
  • ✓ Cycle Navigation: Tap the active status bar anytime to jump back to Home and monitor remaining time.
Multi-Interface Architecture

Home Assistant & Local Web Coexistence

Adding direct Bluetooth Low Energy did not compromise existing smart-home integrations. The ESPHome firmware concurrently maintains its native API port 6053 for Home Assistant, HTTP port 80 for the browser dashboard, and BLE GATT for the companion app.

  • ✓ Home Assistant Integration: Full entity streaming, history graphs, and automated voice routines.
  • ✓ Standalone Web UI: Lightweight embedded dashboard served directly from flash for browser control.
  • ✓ No Cloud Lock-in: Control the machine entirely over local Bluetooth without active internet or router connection.

BLE GATT Line Protocol Reference

Service UUID 9f6d1c30-5f2e-4d8a-b7c3-00a1b2c3e001 operating with 1 Hz telemetry pushes and MTU reassembly.

gatt-protocol-session.log 115200 baud / BLE 
// 1. Inbound Command Characteristic (...e002 write):
> WASH 600                  // Start wash agitation mode for 600 seconds
> SPIN 300                  // Engage drain & drum clutch, then spin 300s
> PROG 0                    // Execute saved sequence in Slot 0 (Cepat)
> SET WASHMIN 12            // Optimistically update parameter and persist to NVS
> STOP                      // Emergency halt — immediately de-energize all coils

// 2. Outbound Telemetry Characteristic (...e003 read / notify @ 1 Hz):
< ST:WASH|WASH 20min|1/1|120|1080|1000|142|W65
//   Format: ST:<MODE>|<PROG_NAME>|<STEP>/<STEPS>|<ELAPSED_S>|<REMAIN_S>|<ABDI>|<HEAP_KB>|W<WATER%>
//   MODE:      WASH (Agitation active)
//   PROG_NAME: WASH 20min
//   STEP:      1 of 1
//   ELAPSED:   120 seconds elapsed
//   REMAIN:    1080 seconds remaining
//   ABDI:      1000 (Relay A=ON, Relay B=OFF, Drain=OFF, Inlet=OFF)
//   HEAP:      142 KB free
//   WATER:     65% tub level
