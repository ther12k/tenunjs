# v0.1 supersession notice

The earlier TenunJS v0.1 bundle assumed semantic HTML, CSS, HTTP fragment updates, and a tiny browser runtime. That architecture does not satisfy the clarified mobile-native Skia requirement.

## Superseded

- HTML as the primary rendering output
- DOM morphing and fragment patch protocol
- Browser-native controls as the widget implementation
- Bun/Bundar server adapters as the initial host
- Rust/WASM optimization as the likely native role
- “Compose widgets. Ship HTML.” tagline

## Retained at the product-intent level

- TypeScript + TSX authoring
- Flutter-inspired widget composition
- Simple one-file screens
- Optional split view/controller organization
- Explicit action-oriented interactions
- Small, understandable application model

## Replacement

The v0.2 canonical model is:

```text
TSX → controller/reconciler → atomic native mutations → scene/layout/semantics → Skia → iOS/Android
```

No implementation issue may cite v0.1 as an active architecture dependency.
